Day 1: Linked Lists
Introduction to singly and doubly linked lists, insertion/deletion operations, and traversal.

Day 2: Stacks, Queues, and HashMaps
Implementing stacks and queues using arrays and linked lists; overview and usage of HashMap for key-value mapping.

Day 3: Sorting Algorithms
Understanding and implementing Bubble Sort, Selection Sort, and Insertion Sort with performance considerations.

Day 4: File Handling
Reading from and writing to files using Java I/O classes like FileReader, BufferedReader, FileWriter, etc.

Day 5: Linear and Binary Search
Comparing linear and binary search approaches; implementing both methods and understanding their use cases.

Day 6: Algorithm Runtime Analysis
Introduction to Big O notation, best/worst/average case analysis, and space-time tradeoffs.
